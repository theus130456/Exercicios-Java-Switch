# Exercícios Java — Switch 🔀

Coleção de 10 exercícios práticos em Java para treinar a estrutura `switch`, combinada com cálculos de preços, descontos condicionais (`if`) e, em um dos casos, `switch` aninhado.

Repositório: [Milesdev275/Exercicios-Java-Switch](https://github.com/Milesdev275/Exercicios-Java-Switch) · Pasta dos exercícios: [`ExerciciosSwitch/`](https://github.com/Milesdev275/Exercicios-Java-Switch/tree/main/ExerciciosSwitch)

> Clique no número ou no nome de qualquer exercício abaixo para abrir o código-fonte direto no GitHub.

---

## 🔀 Exercícios com `switch`

| # | Exercício | Descrição |
|---|-----------|-----------|
| 01 | [Posto de combustível](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio01.java) | Calcula o valor a pagar conforme o tipo de combustível (Gasolina, Etanol, Diesel) e a quantidade de litros |
| 02 | [Lanchonete](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio02.java) | Calcula o total do pedido com base no item escolhido (hambúrguer, pizza, batata frita, refrigerante ou suco) e na quantidade |
| 03 | [Planos de assinatura](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio03.java) | Calcula o valor de um plano (Básico, Profissional, Premium) por número de meses, com 10% de desconto no plano anual |
| 04 | [Estacionamento](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio04.java) | Calcula o valor a pagar por tipo de veículo (moto, carro, caminhonete) e horas estacionadas, com taxa extra acima de 5h |
| 05 | [Loja de roupas](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio05.java) | Calcula o valor da compra por tipo de produto (camiseta, calça, jaqueta, tênis), com 15% de desconto a partir de 3 unidades |
| 06 | [Frete por região](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio06.java) | Calcula o frete conforme a região do Brasil, com frete grátis para compras acima de R$300 |
| 07 | [Frete por região (v2)](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio07.java) | Mesma lógica do exercício 6: calcula frete por região com isenção acima de R$300 |
| 08 | [Venda de ingressos](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio08.java) | Calcula o valor de ingressos (inteira, meia-entrada, VIP), com 5% de desconto para mais de 4 unidades |
| 09 | [Pet shop (switch aninhado)](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio09.java) | Calcula o valor do serviço (banho, tosa ou banho e tosa) combinado com o porte do animal, usando `switch` dentro de `switch` |
| 10 | [Sorveteria](https://github.com/Milesdev275/Exercicios-Java-Switch/blob/main/ExerciciosSwitch/Exercicio010.java) | Calcula o valor do pedido (açaí, sorvete, milkshake) com adicional opcional por unidade |

## 🛠️ Como executar

```bash
git clone https://github.com/Milesdev275/Exercicios-Java-Switch.git
cd Exercicios-Java-Switch/ExerciciosSwitch
javac Exercicio01.java
java ExerciciosSwitch.Exercicio01
```

Basta trocar `Exercicio01` pelo número do exercício que deseja rodar (os arquivos pertencem ao pacote `ExerciciosSwitch`).
